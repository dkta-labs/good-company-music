# Reference tracks

**How these were inspected:** YouTube's public oEmbed endpoint (title, channel) and each watch page's public metadata (description, duration, tags). All four were publicly playable (`playability: OK`).

**Nobody here heard the audio.** No listening tool was available, and downloading the tracks for analysis would copy copyrighted audio. Nothing below states a tempo, key, melody or instrument as heard. The "derived qualities" come only from the titles, descriptions and tags, and are provisional until someone listens to the references next to the sketches.

The new sketches are original. They don't quote, sample or transcribe any of these tracks.
